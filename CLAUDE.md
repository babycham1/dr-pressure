# CLAUDE.md — Dr. Pressure

Redesign of https://www.drpressureservices.com/ (Dr. Pressure Cleaning Services LLC, South Florida
exterior/pressure cleaning). Plain HTML/CSS/JS, no framework.

## Structure
- `index.html`, `services.html`, `our-work.html`, `quote.html`: generated by `build.py`
  (shared header/footer/quote bar). Edit `build.py`, then run `python build.py`.
- `css/styles.css`: all styles. Brand colors are CSS variables in `:root` (red, blue, black from the logo).
- `js/main.js`: mobile menu, footer year, before/after drag sliders.
- `assets/img/logo.png` (on black, so the header and footer are black), (hero.jpg removed: hero is now a bright CSS background),
  `work/<slug>-before.jpg` and `-after.jpg` (split from the original site's before/after photos).
- `assets/img/hero-pressure-washing.jpg`: stock photo in the home hero card, from Pexels
  (https://www.pexels.com/photo/5652626/, young man pressure washing house siding; Pexels license: free, no
  attribution required). It is NOT the owner's crew; swap in a real job photo when one is available.

## Rules
- Every page must offer "Get a Quote": header button, quote band above the footer, and the
  fixed bottom bar on phones. All of them link to `quote.html`, which embeds the owner's existing
  Tally form (https://tally.so/r/RGGEVv).
- Use only content from the current site or supplied by the owner. Don't invent reviews, stats or claims.
- Check desktop and 375px phone width before calling any change done.
